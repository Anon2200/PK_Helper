# Голосовой ассистент для Windows (локальный, бесплатный)

Работает на вашем ПК: речь (faster-whisper), мозг (Ollama + Qwen), голос (Piper / голос Windows). Без облака, ключей и подписок. Лицензия MIT.

## Установка
1. Распаковать архив в папку, например `C:\assistant`.
2. Запустить `install.bat` (сам поставит Python 3.11, библиотеки, Ollama, Tesseract).
3. Запустить `run.bat`. При первом запуске задать имя ассистента; модели скачаются сами (нужен интернет, несколько ГБ).
4. Для отдельного приложения: `build.bat` (создаст `dist\Assistant\Assistant.exe` и ярлык), затем при желании `build_installer.bat` (создаст `installer\VoiceAssistant_Setup.exe`).

На втором ПК повторить те же шаги: экземпляры независимы (своё имя, настройки, память).

## Как пользоваться
- Скажите «<имя>, <команда>», нажмите 🎤 / `Ctrl+Alt+Пробел`, либо напишите в строку ввода.
- «Стоп» / «Подожди» / кнопка «Стоп» / `Ctrl+Alt+S` — мгновенная остановка.
- Удаление, установка и удаление программ, вход на сайт — только после «да».
- Настройки: значок ⚙ в окне (микрофон, динамики, модель, язык, чувствительность, клавиши, автозапуск, «невидимка», перебивание голосом).

## Свои команды без кода
Файл `data\commands.yaml` (создаётся при первом запуске, внутри пример). Шаги: `open_app`, `close_app`, `open_path`, `hotkey`, `type_text`, `run`, `wait`.

## Добавление инструмента (для разработчика)
В любом модуле `app/tools_*.py`:
```python
@tool("my_tool", "Описание для модели", {"arg": "описание аргумента"}, ["arg"], danger=None)
def my_tool(arg): return "результат"
```
`danger=lambda a: "вопрос"` включает обязательное подтверждение. Новый модуль нужно импортировать в `app/assistant.py`.

## Тесты
`python -m unittest discover tests` — файловые инструменты. Ручной чек-лист приёмки: `tests/CHECKLIST.md`.
