# Архитектура

| Модуль | Назначение |
|---|---|
| `main.py` | запуск, мастер первого запуска, окно, режим «невидимка» |
| `app/assistant.py` | оркестратор: слушание, имя, подтверждения, цикл «LLM → инструмент → LLM», стоп |
| `app/audio.py` | запись фразы с определением паузы |
| `app/stt.py` | faster-whisper (RU/EN, int8) |
| `app/tts.py` | Piper (exe скачивается сам) → запасной голос Windows |
| `app/llm.py` | Ollama: сервер, скачивание модели, chat с tools |
| `app/tools.py` | реестр инструментов (`@tool`), файловые операции |
| `app/tools_gui.py` | окна (UIA), мышь, клавиатура, скриншоты, OCR |
| `app/tools_browser.py` | Playwright + Edge, поиск, формы, вход, загрузки |
| `app/tools_system.py` | winget, громкость, яркость, настройки, память, секреты, план |
| `app/usercmds.py` | команды из `data/commands.yaml` |
| `app/secrets_store.py` | пароли через Windows DPAPI |
| `app/memory.py` | SQLite: предпочтения (журнал действий не ведётся) |
| `app/gui.py` | интерфейс, сфера, настройки |

Политика безопасности: инструмент с `danger` не выполняется без «да»; секреты не попадают в ответы; сетевых вызовов, отправляющих данные пользователя, нет (скачивание моделей и страниц — только входящие).
Цепочка автоматизации: специальные инструменты → UIA (`focus_window`, `uia_click`) → мышь/клавиатура + OCR → вопрос пользователю.
